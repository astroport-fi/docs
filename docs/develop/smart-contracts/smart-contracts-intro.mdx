# Smart Contracts

Astroport's contracts run on Terra (`phoenix-1`) and Neutron (`neutron-1`) and are in long-term support: they stay live, and changes are limited to security fixes and maintenance. The "Astroport - Contributors" DAO on each chain controls them through the protocol owner contracts. There is no token governance.

- [**Contract Addresses**](./contract-addresses): every live contract with its version, plus retired contracts.
- [**Source Code and Versions**](./github-commits): where the source lives and how to check a deployed contract.
- [**Common Types**](./common-types): shared types such as `AssetInfo`, `Asset` and `PairInfo`.
- [**Factory**](./factory): creates pools and keeps the registry of pools and pool types.
- [**Swap Pairs**](./swap-pairs/swap-pairs-intro): constant product, stableswap, PCL and exit-only pools.
- [**Oracle**](./oracle): a demo TWAP contract.
- [**Router**](./router): multi-hop swaps. Router 2.0 is recommended.
- [**ASTRO Token**](./token): ASTRO denoms, supply and legacy tokens.
- [**Tokenomics**](./tokenomics/tokenomics-intro): Maker, ASTRO burner, yASTRO, Incentives, Vesting, and the retired xASTRO staking.
- [**Periphery Contracts**](./periphery/periphery-contracts-intro): native coin registry, liquidity manager and helpers.
- [**Access Controls and Permissions**](./access-controls-and-permissions): who owns and admins each contract.
