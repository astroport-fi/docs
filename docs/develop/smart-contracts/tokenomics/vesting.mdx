# Vesting

## Overview

The Vesting contract unlocks a token for registered accounts along time-based schedules. Astroport used it to fund ASTRO emissions: the Generator, and later [Incentives](./incentives), had vesting accounts and claimed ASTRO from them to pay LP stakers.

<Admonition type="info" title="NOTE">
  ASTRO emissions are zero under long-term support. Every schedule registered in the Terra and Neutron Vesting contracts ended in 2024.
</Admonition>

The vested token is set at instantiate as an [`AssetInfo`](../common-types#assetinfo): ASTRO (IBC) on Terra and ASTRO (tokenfactory) on Neutron.

## ExecuteMsg

### `claim`

Sends the sender's unlocked tokens, across all of its schedules, to `recipient` (default: the sender). Without `amount`, everything available is sent; with it, `amount` must not exceed what's available.

<CH.Section>
    <CH.Code>

        ```json json
        {
            "claim": {
                "recipient": "neutron1...",
                "amount": "1000000"
            }
        }
        ```

        ```rust vesting.rs
        #[cw_serde]
        pub enum ExecuteMsg {
            Claim {
                recipient: Option<String>,
                amount: Option<Uint128>,
            },
            Receive(Cw20ReceiveMsg),
            RegisterVestingAccounts {
                vesting_accounts: Vec<VestingAccount>,
            },
            WithdrawFromActiveSchedule {
                account: String,
                recipient: Option<String>,
                withdraw_amount: Uint128,
            },
            ProposeNewOwner {
                owner: String,
                expires_in: u64,
            },
            DropOwnershipProposal {},
            ClaimOwnership {},
        }
        ```

    </CH.Code>

| **Params**      | **Type** | **Description** |
| ----------- | ----------- | ----------- |
| [`recipient`](focus://json#3)   | `Option<String>`   | The address that receives the tokens. Defaults to the sender      |
| [`amount`](focus://json#4)   | `Option<Uint128>`   | The amount to claim. Defaults to everything available      |

</CH.Section>

### `register_vesting_accounts`

Owner only. Registers vesting schedules for one or more accounts. The tokens for every schedule must be paid in the same call: for a native vesting token, attach exactly the sum of the schedules' amounts; for a CW20 vesting token, use the CW20 `receive` hook below.

<CH.Section>
    <CH.Code>

        ```json json
        {
            "register_vesting_accounts": {
                "vesting_accounts": [
                    {
                        "address": "neutron1...",
                        "schedules": [
                            {
                                "start_point": {
                                    "time": 1798416000,
                                    "amount": "0"
                                },
                                "end_point": {
                                    "time": 1830038400,
                                    "amount": "1000000000"
                                }
                            }
                        ]
                    }
                ]
            }
        }
        ```

        ```rust vesting.rs
        #[cw_serde]
        pub struct VestingAccount {
            pub address: String,
            pub schedules: Vec<VestingSchedule>,
        }

        #[cw_serde]
        pub struct VestingSchedule {
            pub start_point: VestingSchedulePoint,
            pub end_point: Option<VestingSchedulePoint>,
        }

        #[cw_serde]
        pub struct VestingSchedulePoint {
            pub time: u64,
            pub amount: Uint128,
        }
        ```

    </CH.Code>

| **Params**      | **Type** | **Description** |
| ----------- | ----------- | ----------- |
| [`address`](focus://json#5)   | `String`     | The account receiving the tokens      |
| [`schedules`](focus://json#6:17)   | `Vec<VestingSchedule>`     | The account's schedules      |
| [`start_point`](focus://json#8:11)   | `VestingSchedulePoint`     | Time (seconds) and amount unlocked at the start. Without an `end_point`, the whole `amount` unlocks at `time`      |
| [`end_point`](focus://json#12:15)   | `Option<VestingSchedulePoint>`     | Time and total amount unlocked at the end. Between the two points, tokens unlock linearly      |

</CH.Section>

### `receive`

CW20 receive hook, for a CW20 vesting token. Send the tokens from the owner with a CW20 `send` whose `msg` is the base64 of a `register_vesting_accounts` message (same fields as above).

```json
{
    "send": {
        "contract": "<vesting contract>",
        "amount": "1000000000",
        "msg": "<base64 of {\"register_vesting_accounts\":{\"vesting_accounts\":[...]}}>"
    }
}
```

### `withdraw_from_active_schedule`

Owner only. Takes `withdraw_amount` of the still-locked tokens out of an account's only active schedule and sends them to `recipient` (default: the owner). The schedule restarts from now with what's left. Fails if the account has no active schedule or more than one.

```json
{
    "withdraw_from_active_schedule": {
        "account": "neutron1...",
        "recipient": "neutron1...",
        "withdraw_amount": "1000000"
    }
}
```

### `propose_new_owner`, `drop_ownership_proposal`, `claim_ownership`

Two-step ownership transfer. The owner proposes a new owner with an expiry in seconds, or drops the proposal; the proposed owner claims ownership.

```json
{
    "propose_new_owner": {
        "owner": "neutron1...",
        "expires_in": 86400
    }
}
```

        ```json json
        }
        ```


    </CH.Code>

</CH.Section>

### `vesting_account`

Returns an account's schedules and how much it has already claimed.

<CH.Section>
    <CH.Code>

        ```json json
        {
            "vesting_account": {
                "address": "neutron173fd8wpfzyqnfnpwq2zhtgdstujrjz2wkprkjfr6gqg4gknctjyq6m3tch"
            }
        }
        ```

        ```rust vesting.rs
        #[cw_serde]
        pub struct VestingAccountResponse {
            pub address: Addr,
            pub info: VestingInfo,
        }

        #[cw_serde]
        pub struct VestingInfo {
            pub schedules: Vec<VestingSchedule>,
            pub released_amount: Uint128,
        }
        ```

    </CH.Code>

| **Params**      | **Type** | **Description** |
| ----------- | ----------- | ----------- |
| `address`   | `Addr`     | The account      |
| `info.schedules`   | `Vec<VestingSchedule>`     | Its schedules      |
| `info.released_amount`   | `Uint128`     | The total already claimed      |

</CH.Section>

### `vesting_accounts`

Returns several accounts, paginated. `order_by` is `"asc"` or `"desc"`.

```json
{
    "vesting_accounts": {
        "start_after": null,
        "limit": 10,
        "order_by": "asc"
    }
}
```

The response is `{"vesting_accounts": [<VestingAccountResponse>, ...]}`.

### `available_amount`

Returns the amount an account can claim right now, as a `Uint128`.

```json
{
    "available_amount": {
        "address": "neutron173fd8wpfzyqnfnpwq2zhtgdstujrjz2wkprkjfr6gqg4gknctjyq6m3tch"
    }
}
```

### `timestamp`

Returns the current block time in seconds, as a `u64`.

```json
{
    "timestamp": {}
}
```
