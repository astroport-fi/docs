# Factory

## Overview

The factory creates new Astroport pools (and their LP tokens) and keeps the registry of pools, one per set of assets. It also holds the configuration of every pool type it can create: the code ID, the fees and whether anyone can create that type.

The factory owner is the protocol owner on each chain: the satellite ("Astroport Assembly") on Terra and the Assembly on Neutron, both run by the Astroport Contributors DAO (see [Access Controls and Permissions](./access-controls-and-permissions.mdx)). Only the owner can change the configuration or deregister pools.

Pool types and fees configured on mainnet (2026-11-04):

| Pair type | Terra (factory 1.8.0) | Neutron (factory 1.9.0) |
| ----------- | ----------- | ----------- |
| `{"xyk": {}}` | 30 bps, 1/3 to Maker (`maker_fee_bps` 3333) | 30 bps, 1/3 to Maker |
| `{"stable": {}}` | 5 bps, 1/2 to Maker (5000) | 5 bps, 1/2 to Maker |
| `{"custom": "concentrated"}` (PCL) | Fee set per pool by its parameters, 1/2 to Maker | Same |
| Concentrated with Duality orderbook | n/a | Fee set per pool, 1/2 to Maker |
| Transmuter | Permissioned, no fees | Permissioned |
| xASTRO pair (xASTRO is retired) | n/a | Permissioned, can't be incentivized |
| XYK with sale tax | n/a | Disabled |

## InstantiateMsg

Initializes the factory with the pool types it can create, the Maker (`fee_address`), the Incentives contract, the coin registry and the owner.

<CH.Code>

```json json

    {
      "code_id": 123,
      "pair_type": {
        "xyk": {}
      },
      "total_fee_bps": 30,
      "maker_fee_bps": 3333,
      "is_disabled": false,
      "is_generator_disabled": false,
      "permissioned": false
    }
  ],
  "token_code_id": 69,
  "fee_address": "terra1ygcvxp9s054q8u2q4hvl52ke393zvgj0sllahlycm4mj8dm96zjsa45rzk",
  "generator_address": "terra1eywh4av8sln6r45pxq45ltj798htfy0cfcf7fy3pxc2gcv6uc07se4ch9x",
  "owner": "terra1k9j8rcyk87v5jvfla2m9wp200azegjz0eshl7n2pwv852a7ssceqsnn7pq",
  "whitelist_code_id": 70,
  "coin_registry_address": "terra1zuf8fla02926nhpfvk09k2pg6qv9aayflp0qt4a0msppu2h4exqs6af275",
  "tracker_config": {
    "code_id": 123,
    "token_factory_addr": "terra1..."
  }
}
```

```rust factory.rs

pub struct InstantiateMsg {

    pub generator_address: Option<String>,
    pub owner: String,
    pub whitelist_code_id: u64,
    pub coin_registry_address: String,
    pub tracker_config: Option<TrackerConfig>,

```

</CH.Code>

| **Params** | **Type** | **Description** |
| ----------- | ----------- | ----------- |
| [`pair_configs`](focus://json#2:14) | [`Vec<PairConfig>`](#pairconfig) | The pool types the factory can create |
| [`token_code_id`](focus://json#15) | `u64` | CW20 token code ID, used by pool versions that issue a CW20 LP token |
| [`fee_address`](focus://json#16) | `Option<String>` | The Maker contract, which receives the Maker share of swap fees |
| [`generator_address`](focus://json#17) | `Option<String>` | The Incentives contract. Pools stake LP tokens there when `auto_stake` is set, and `deregister` deactivates the pool there |
| [`owner`](focus://json#18) | `String` | Address allowed to change the factory configuration |
| [`whitelist_code_id`](focus://json#19) | `u64` | CW1 whitelist code ID, used to store third-party staking rewards |
| [`coin_registry_address`](focus://json#20) | `String` | The native coin registry, which stores the decimals of native denoms |
| [`tracker_config`](focus://json#21:24) | `Option<TrackerConfig>` | Code ID of the tokenfactory tracker and the tokenfactory module address, for pools that track LP balances |

</CH.Section>

#### `PairConfig`

The configuration of a pool type.

<CH.Section>
<CH.Code>

```json json
{
  "code_id": 123,
  "pair_type": {
    "xyk": {}
  },
  "total_fee_bps": 30,
  "maker_fee_bps": 3333,
  "is_disabled": false,
  "is_generator_disabled": false,
  "permissioned": false,
  "whitelist": null
```

```rust factory.rs
#[cw_serde]
pub struct PairConfig {
    pub code_id: u64,
    pub pair_type: PairType,
    pub total_fee_bps: u16,
    pub maker_fee_bps: u16,
    #[serde(default)]
    pub is_disabled: bool,
    #[serde(default)]
    pub is_generator_disabled: bool,
    #[serde(default)]
    pub permissioned: bool,
    #[serde(default)]
    pub whitelist: Option<Vec<String>>,
}
```

</CH.Code>

| **Params** | **Type** | **Description** |
| ----------- | ----------- | ----------- |
| [`code_id`](focus://json#2) | `u64` | Code ID used to instantiate pools of this type |
| [`pair_type`](focus://json#3:5) | [`PairType`](#pairtype) | The pool type |
| [`total_fee_bps`](focus://json#6) | `u16` | Total swap fee in basis points (at most 10,000). Pool types with their own fee model, such as PCL, set fees in the pool parameters instead |
| [`maker_fee_bps`](focus://json#7) | `u16` | Share of the swap fee sent to the Maker, in basis points of the fee (10,000 = 100%) |
| [`is_disabled`](focus://json#8) | `bool` | If true, no new pools of this type can be created. Existing pools keep working |
| [`is_generator_disabled`](focus://json#9) | `bool` | If true, pools of this type can't be incentivized in the Incentives contract |
| [`permissioned`](focus://json#10) | `bool` | If true, only the owner (or, from 1.10.0, an address in `whitelist`) can create pools of this type |
| [`whitelist`](focus://json#11) | `Option<Vec<String>>` | 1.10.0 only. Addresses allowed to create pools of a permissioned type |

</CH.Section>

### `update_pair_config`

Adds a pool type or replaces its configuration: code ID, fees, and whether it is disabled, can be incentivized or is permissioned. Only the owner can call it. Fee changes apply to existing pools of the type, since pools read their fees from the factory.

As an example, a pool type that charges 30 bps and sends 1/3 of it to the Maker has `total_fee_bps` 30 and `maker_fee_bps` 3333: 3333 / 10,000 * 30 bps = 0.1% of each swap goes to the Maker.

<CH.Section>
<CH.Code>

```json json
{
  "update_pair_config": {
    "config": {
      "code_id": 123,
      "pair_type": {
        "xyk": {}
      },
      "total_fee_bps": 30,
      "maker_fee_bps": 3333,
      "is_disabled": false,
      "is_generator_disabled": false,
      "permissioned": false
    }
  }
}
```

```rust factory.rs
UpdatePairConfig {
    config: PairConfig,
},
```

</CH.Code>

| **Params** | **Type** | **Description** |
| ----------- | ----------- | ----------- |
| [`config`](focus://json#3:13) | [`PairConfig`](#pairconfig) | The new configuration of the pool type |

</CH.Section>

### `create_pair`

Creates a pool and registers it. Anyone can call it unless the pool type is permissioned. It fails if a pool for these assets already exists or if the type is disabled. The pool is instantiated with the factory owner as its admin. Pools mint a tokenfactory LP denom, so attach the chain's tokenfactory denom creation fee, if any, as funds; the factory passes them to the pool.

Custom pool types may need extra parameters, packed in `init_params` (see each pool page).

<CH.Section>
<CH.Code>

```json json
{
  "create_pair": {
    "pair_type": {
      "xyk": {}
    },
    "asset_infos": [
      {
        "native_token": {
          "denom": "uluna"
        }
      },
      {
        "native_token": {
          "denom": "ibc/E8481AD838C31D4FC12A504B10F9B4E2F830F8818D2735C2FFC707579B5FA60B"
        }
      }
    ],
    "init_params": null
  }
}
```

```rust factory.rs
CreatePair {
    pair_type: PairType,
    asset_infos: Vec<AssetInfo>,
    init_params: Option<Binary>,
},
```

</CH.Code>

| **Params** | **Type** | **Description** |
| ----------- | ----------- | ----------- |
| [`pair_type`](focus://json#3:5) | [`PairType`](#pairtype) | The pool type |
| [`asset_infos`](focus://json#6:17) | [`Vec<AssetInfo>`](./common-types.mdx#assetinfo) | The assets of the pool |
| [`init_params`](focus://json#18) | `Option<Binary>` | Base64-encoded pool parameters for types that need them |
