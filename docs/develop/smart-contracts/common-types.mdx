# Common Types

## Overview

Types used across Astroport contracts, from the `astroport` package.

## Links

- **Github:** https://github.com/astroport-fi/astroport-core/tree/main/packages/astroport
- **asset.rs:** https://github.com/astroport-fi/astroport-core/blob/main/packages/astroport/src/asset.rs
- **common.rs:** https://github.com/astroport-fi/astroport-core/blob/main/packages/astroport/src/common.rs

## Data Types

### `AssetInfo`

Identifies an asset: a native denom (bank, IBC or tokenfactory, such as `uluna` or `factory/<creator>/<subdenom>`) or a CW20 token contract.

<CH.Section>
<CH.Code>

```rust asset.rs
#[cw_serde]
pub enum AssetInfo {
    Token { contract_addr: Addr },
    NativeToken { denom: String },
}
```

</CH.Code>

| **Variants** | **Description** |
| ----------- | ----------- |
| `token` | A CW20 token: `{"token": {"contract_addr": "terra1..."}}` |
| `native_token` | A native denom: `{"native_token": {"denom": "uluna"}}` |

</CH.Section>

### `Asset`

An asset and an amount.

<CH.Section>
<CH.Code>

```json json
{
  "info": {
    "native_token": {
      "denom": "ibc/8D8A7F7253615E5F76CB6252A1E1BD921D5EDB7BBAAF8913FB1C77FF125D9995"
    }
  },
  "amount": "1000000"
}
```

```rust asset.rs
#[cw_serde]
pub struct Asset {
    pub info: AssetInfo,
    pub amount: Uint128,
}
```

</CH.Code>

| **Params** | **Type** | **Description** |
| ----------- | ----------- | ----------- |
| [`info`](focus://json#2:6) | [`AssetInfo`](#assetinfo) | The asset |
| [`amount`](focus://json#7) | `Uint128` | The amount, in the asset's smallest unit |

</CH.Section>

### `PairInfo`

Describes a pool. Returned by a pool's `pair` query and the factory's `pair` and `pairs` queries.

<CH.Section>
<CH.Code>

```json json
{
  "asset_infos": [
    {
      "native_token": {
        "denom": "uluna"
      }
    },
    {
      "native_token": {
        "denom": "ibc/E8481AD838C31D4FC12A504B10F9B4E2F830F8818D2735C2FFC707579B5FA60B"
      }
    }
  ],
  "contract_addr": "terra1...pool",
  "liquidity_token": "factory/terra1...pool/astroport/share",
  "pair_type": {
    "xyk": {}
  }
}
```

```rust asset.rs
#[cw_serde]
pub struct PairInfo {
    pub asset_infos: Vec<AssetInfo>,
    pub contract_addr: Addr,
    pub liquidity_token: String,
    pub pair_type: PairType,
}
```

</CH.Code>

| **Params** | **Type** | **Description** |
| ----------- | ----------- | ----------- |
| [`asset_infos`](focus://json#2:13) | [`Vec<AssetInfo>`](#assetinfo) | The pool's assets |
| [`contract_addr`](focus://json#14) | `Addr` | The pool contract address |
| [`liquidity_token`](focus://json#15) | `String` | The LP token: a tokenfactory denom (`factory/<pool>/astroport/share`) for current pools, or a CW20 address for older ones |
| [`pair_type`](focus://json#16:18) | [`PairType`](./factory.mdx#pairtype) | The pool type |

</CH.Section>

### `OwnershipProposal`

A pending offer to change a contract's owner, created by `propose_new_owner`.

<CH.Section>
<CH.Code>

```json json
{
  "owner": "terra1...",
  "ttl": 1731300000
}
```

```rust common.rs
#[cw_serde]
pub struct OwnershipProposal {
    pub owner: Addr,
    pub ttl: u64,
}
```

</CH.Code>

| **Params** | **Type** | **Description** |
| ----------- | ----------- | ----------- |
| [`owner`](focus://json#2) | `Addr` | The proposed owner |
| [`ttl`](focus://json#3) | `u64` | Time (in seconds since epoch) when the offer expires |

</CH.Section>
