# Contract Addresses

Astroport runs on Terra (`phoenix-1`) and Neutron (`neutron-1`). Both deployments are in long-term support: the contracts stay live, and changes are limited to security fixes and maintenance. Versions are the `cw2` contract versions reported on chain (checked on 2026-11-04).

<Admonition type="info" title="NOTE">
  Testnet deployments are no longer maintained. Astroport no longer supports Sei, Injective, Osmosis or Terra Classic.
</Admonition>

### Pools

Pools are not listed here. Every pool created through the factory can be looked up with the factory's [`pair`](./factory#pair) and [`pairs`](./factory#pairs) queries, and each pool reports its own address, assets, LP token and type with its `pair {}` query.

Six Neutron pools that were drained in the September 2026 incident now run `astroport-pair-exit-only` 1.0.0: they only allow balanced withdrawals. The migration keeps their stored cw2 version, so they still report the pool contract they ran before. See [Exit-only pools](./swap-pairs/exit-only-pools).
