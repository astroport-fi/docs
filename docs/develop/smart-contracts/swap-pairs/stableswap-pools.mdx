# Stableswap Pools

## Overview

The stableswap pool uses the 4A(Rx+Ry) + D formula, resulting in a constant price ∆x / ∆y = 1. More details around how the pool functions can be found [here](/docs/learn/astro-pools/stableswap-pools).

A stableswap pool holds two assets. New pools mint a tokenfactory LP denom, `factory/<pool address>/astroport/share`. The pool has an optional owner set in `init_params`; if none is set, the factory owner acts as owner.

## Links

- **Contract Repo:** https://github.com/astroport-fi/astroport-core/tree/main/contracts/pair_stable
- **contract.rs:** https://github.com/astroport-fi/astroport-core/blob/main/contracts/pair_stable/src/contract.rs

- **Tests:** https://github.com/astroport-fi/astroport-core/tree/main/contracts/pair_stable/tests
- **Version documented:** `astroport-pair-stable` 4.2.0 (astroport-core main). Pools created at different times can run older versions; a pool's cw2 `contract_info` shows its version.

## InstantiateMsg

Pools are instantiated by the [factory](../factory.mdx#create_pair), not directly. The factory passes this message to the pool; you only choose `pair_type`, `asset_infos` and `init_params` in `create_pair`.

<CH.Section>
<CH.Code>

```json json
{
  "pair_type": {
    "stable": {}
  },
  "asset_infos": [
    {
      "native_token": {
        "denom": "ibc/E8481AD838C31D4FC12A504B10F9B4E2F830F8818D2735C2FFC707579B5FA60B"
      }
    },
    {
      "native_token": {
        "denom": "ibc/2C962DAB9F57FE0921435426AE75196009FAA1981BF86991203C8411F8980FDB"
      }
    }
  ],
  "token_code_id": 69,
  "factory_addr": "terra14x9fr055x5hvr48hzy2t4q7kvjvfttsvxusa4xsdcy702mnzsvuqprer8r",
  "init_params": "eyJhbXAiOjEwMCwib3duZXIiOm51bGx9"
}
```

```rust pair.rs
#[cw_serde]
pub struct InstantiateMsg {
    pub pair_type: PairType,
    pub asset_infos: Vec<AssetInfo>,
    pub token_code_id: u64,
    pub factory_addr: String,
    pub init_params: Option<Binary>,
}
```

</CH.Code>

| **Params** | **Type** | **Description** |
| ----------- | ----------- | ----------- |
| [`pair_type`](focus://json#2:4) | [`PairType`](../factory.mdx#pairtype) | The pool type |
| [`asset_infos`](focus://json#5:16) | [`Vec<AssetInfo>`](../common-types.mdx#assetinfo) | The two assets in the pool |
| [`token_code_id`](focus://json#17) | `u64` | CW20 code ID kept in the factory config. New pools use a tokenfactory LP denom, so it isn't used for the LP token |
| [`factory_addr`](focus://json#18) | `String` | The factory contract address |
| [`init_params`](focus://json#19) | `Option<Binary>` | Required base64-encoded `StablePoolParams`: `amp` (amplification, greater than 0 and at most 1,000,000) and an optional `owner` |

</CH.Section>

## ExecuteMsg

### `receive`

CW20 receive hook. A CW20 offer asset is swapped by sending it to the pool with the CW20 `send` message and a base64-encoded `swap` hook. CW20 tokens can't be swapped with `swap` directly.

<CH.Section>
<CH.Code>

```json json
{
  "receive": {
    "sender": "terra1...",
    "amount": "1000000",
    "msg": "<base64_encoded_json_string>"
  }
}
```

```rust pair.rs
Receive(Cw20ReceiveMsg),
```

</CH.Code>

| **Params** | **Type** | **Description** |
| ----------- | ----------- | ----------- |
| [`receive`](focus://json#2:6) | [`Cw20ReceiveMsg`](https://docs.rs/cw20/latest/cw20/struct.Cw20ReceiveMsg.html) | CW20 receive message |

</CH.Section>

The hook embedded in `msg`. The offer asset and amount come from the CW20 transfer.

### `provide_liquidity`

Deposits assets into the pool and mints LP tokens. Native assets are attached to the message as funds. CW20 assets are pulled with `transfer_from`, so you must first increase the pool's allowance for them. On the first deposit, a small amount of LP is minted to the pool itself and stays locked.

<CH.Section>
<CH.Code>

```json json
{
  "provide_liquidity": {
    "assets": [
      {
        "info": {
          "native_token": {
            "denom": "ibc/E8481AD838C31D4FC12A504B10F9B4E2F830F8818D2735C2FFC707579B5FA60B"
          }
        },
        "amount": "1000000"
      },
      {
        "info": {
          "native_token": {
            "denom": "ibc/2C962DAB9F57FE0921435426AE75196009FAA1981BF86991203C8411F8980FDB"
          }
        },
        "amount": "1000000"
      }
    ],
    "slippage_tolerance": "0.01",
    "auto_stake": true,
    "receiver": "terra1...",
    "min_lp_to_receive": "990000"
  }
}
```

```rust pair.rs
ProvideLiquidity {
    assets: Vec<Asset>,
    slippage_tolerance: Option<Decimal>,
    auto_stake: Option<bool>,
    receiver: Option<String>,
    min_lp_to_receive: Option<Uint128>,

```

</CH.Code>

| **Params** | **Type** | **Description** |
| ----------- | ----------- | ----------- |
| [`assets`](focus://json#3:20) | [`Vec<Asset>`](../common-types.mdx#asset) | The assets to deposit |
| [`slippage_tolerance`](focus://json#21) | `Option<Decimal>` | Fails the deposit if the pool price moves more than this against the deposit ratio |
| [`auto_stake`](focus://json#22) | `Option<bool>` | If true, the minted LP tokens are staked in the [Incentives](../tokenomics/incentives.mdx) contract on behalf of `receiver`. Defaults to false |

| [`min_lp_to_receive`](focus://json#24) | `Option<Uint128>` | Fails the deposit if fewer LP tokens would be minted |

</CH.Section>

### `withdraw_liquidity`

Burns LP tokens and returns the matching share of each pool asset. Attach the LP tokens (the pool's tokenfactory denom, for example `factory/terra1...pool/astroport/share`) as funds. Only balanced withdrawals are allowed: leave `assets` empty, otherwise the call fails. LP tokens staked in Incentives must be unstaked first. Older pools with a CW20 LP token are withdrawn from by sending the LP token to the pool with a `{"withdraw_liquidity":{}}` hook.

<CH.Section>
<CH.Code>

```json json
{
  "withdraw_liquidity": {
    "assets": [],
    "min_assets_to_receive": [
      {
        "info": {
          "native_token": {
            "denom": "uluna"
          }
        },
        "amount": "990000"
      },
      {
        "info": {
          "native_token": {
            "denom": "ibc/E8481AD838C31D4FC12A504B10F9B4E2F830F8818D2735C2FFC707579B5FA60B"
          }
        },
        "amount": "247000"
      }
    ]
  }
}
```

```rust pair.rs
WithdrawLiquidity {

```

</CH.Code>

| **Params** | **Type** | **Description** |
| ----------- | ----------- | ----------- |

### `update_config`

Changes the amplification or fee sharing. Only the pool owner (or the factory owner if the pool has none) can call it. `params` is a base64-encoded `StablePoolUpdateParams`.

<CH.Section>
<CH.Code>

```json json
{
  "update_config": {
    "params": "eyJzdGFydF9jaGFuZ2luZ19hbXAiOnsibmV4dF9hbXAiOjIwMCwibmV4dF9hbXBfdGltZSI6MTczMTMwMDAwMH19"
  }
}
```

```rust pair.rs
UpdateConfig { params: Binary },

#[cw_serde]
pub enum StablePoolUpdateParams {
    StartChangingAmp {
        next_amp: u64,
        next_amp_time: u64,
    },
    StopChangingAmp {},
    EnableFeeShare {
        fee_share_bps: u16,
        fee_share_address: String,
    },
    DisableFeeShare,
}
```

</CH.Code>

| **Params** | **Type** | **Description** |
| ----------- | ----------- | ----------- |
| [`params`](focus://json#3) | `Binary` | Base64-encoded `StablePoolUpdateParams` |

| **Variants** | **Description** |
| ----------- | ----------- |
| `start_changing_amp { next_amp, next_amp_time }` | Moves the amplification gradually to `next_amp`, reached at `next_amp_time`. The change takes at least one day and changes amp by at most a factor of 10 |
| `stop_changing_amp {}` | Stops the change and keeps the current amplification |
| `enable_fee_share { fee_share_bps, fee_share_address }` | Sends `fee_share_bps` of each swap's fee to `fee_share_address`. Greater than 0 and at most 1000 (10%) |
| `disable_fee_share` | Stops fee sharing |

</CH.Section>
