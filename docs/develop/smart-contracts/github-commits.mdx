# Source Code and Versions

## Repositories

- **astroport-core** (https://github.com/astroport-fi/astroport-core): factory, pools, router, Maker, ASTRO burner, yASTRO, Incentives, Vesting, xASTRO staking, xASTRO payout and the periphery contracts.
- **astroport-governance** (https://github.com/astroport-fi/astroport-governance): the Assembly, the satellite, builder unlock and the retired governance contracts (vxASTRO, emissions controller, tributes).
- **astroport-changelog** (https://github.com/astroport-fi/astroport-changelog): deployment history.

## Checking a deployed contract

- **Version:** every Astroport contract stores its name and version under the `cw2` key `contract_info`. Query it as raw contract state, for example `neutrond query wasm contract-state raw <address> 636F6E74726163745F696E666F` (the hex of `contract_info`), or through any explorer's contract page.
- **Code:** `neutrond query wasm contract <address>` (or `terrad`) returns the code ID and the wasm admin. `query wasm code-info <code_id>` returns the code's checksum, which you can compare with the SHA-256 of a wasm built with the optimizer from the tagged source.
