# ASTRO Token

## Overview

ASTRO is a tokenfactory denom on Neutron. On Terra, ASTRO is the same token, transferred over IBC from Neutron.

| Chain | ASTRO | Notes |
| :-- | :-- | :-- |
| Neutron | `factory/neutron1ffus553eet978k024lmssw0czsxwr97mggyv85lpcsdkft8v9ufsz3sa07/astro` | Tokenfactory denom. Its admin is the [ASTRO burner](./tokenomics/astro-burner) |
| Terra | `ibc/8D8A7F7253615E5F76CB6252A1E1BD921D5EDB7BBAAF8913FB1C77FF125D9995` | Neutron ASTRO over IBC (`transfer/channel-229`) |

## Supply

- ASTRO supply started at 1,000,000,000.
- The Neutron Treasury burn on 2026-10-08 burned 302,664,416.43 ASTRO.
- Supply on 2026-11-04 was 696,235,077.66 ASTRO, and it only goes down: Neutron fees and a quarter of Terra fees are bought as ASTRO and burned (see [Maker](./tokenomics/maker)).
- Minting is impossible in practice. The denom admin is the ASTRO burner contract, which can only burn.
- There are no ASTRO emissions.

## Legacy ASTRO tokens

ASTRO was first a CW20 token on Terra. It moved to Neutron as a tokenfactory denom, and the old tokens are converted, one way and 1:1, through converter pools (`astroport-pair-converter` 1.1.0). A converter pool holds no liquidity and charges no fee: swapping the old token in it returns new ASTRO released by the ASTRO converter contract behind it, so a conversion only goes through while that converter holds enough new ASTRO. The reverse direction isn't supported.
