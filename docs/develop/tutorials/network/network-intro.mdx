# Network

Astroport runs on Terra (`phoenix-1`) and Neutron (`neutron-1`). You can use its contracts directly, without the Astroport app. The [Trading](../trading/trading-intro) and [Farming](../farming/farming-intro) tutorials show the contract messages, with [CosmJS](https://github.com/cosmos/cosmjs) examples. These pages show how to connect:

- [Cosmos Chains](cosmos-chains): chain settings and endpoints for both chains, REST queries from a shell, and CosmJS queries and transactions.
- [Terra](terra-2): Terra settings, assets and CosmJS setup.
- [Neutron](neutron): Neutron settings, assets and CosmJS setup.

Contract addresses for both chains are on the [Contract Addresses](/docs/develop/smart-contracts/contract-addresses) page.
