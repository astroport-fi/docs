# Cosmos Chains

## Overview

Astroport runs on two Cosmos chains, Terra and Neutron. Both are CosmWasm chains, so the same tools work on each: a REST (LCD) endpoint for queries from a shell, and [CosmJS](https://github.com/cosmos/cosmjs) for queries and transactions from JavaScript.

| | Terra | Neutron |
| --- | ----- | ------- |
| Chain ID | `phoenix-1` | `neutron-1` |
| Address prefix | `terra` | `neutron` |
| Fee denom | `uluna` (6 decimals) | `untrn` (6 decimals) |
| HD path (coin type) | `m/44'/330'/0'/0/0` (330) | `m/44'/118'/0'/0/0` (118) |
| RPC | `https://terra-rpc.publicnode.com` | `https://neutron-rpc.polkachu.com` |
| REST (LCD) | `https://terra-rest.publicnode.com` | `https://neutron-api.polkachu.com` |
| Explorer | [terrasco.pe](https://terrasco.pe/mainnet) | [Celatone](https://neutron.celat.one/neutron-1), [Mintscan](https://www.mintscan.io/neutron) |

These are public endpoints run by third parties. They are fine for testing; for production, run your own node or pick a provider from the [Cosmos chain registry](https://github.com/cosmos/chain-registry). Astroport's contract addresses are on the [Contract Addresses](/docs/develop/smart-contracts/contract-addresses) page. Testnet deployments are not maintained.

## Querying with a Shell

A smart query is a `GET` request to the REST endpoint with the query JSON encoded in base64:

```bash
curl "{REST_ENDPOINT}/cosmwasm/wasm/v1/contract/{CONTRACT_ADDRESS}/smart/{BASE64_QUERY}"
```

### Step 1: Write the Query

This example asks the Terra Router 2.0 contract for its configuration:

```json
{
  "config": {}
}
```

### Step 2: Encode It

```bash
echo -n '{"config":{}}' | base64
# eyJjb25maWciOnt9fQ==
```

### Step 3: Send the Request

```bash
curl "https://terra-rest.publicnode.com/cosmwasm/wasm/v1/contract/terra1txm8xcy8mete9e5zh5ktqr4jm4cq4ja8djttg3zkqll64x4ksq7qknaesf/smart/eyJjb25maWciOnt9fQ=="
```

The response wraps the contract's answer in `data`:

```json
{
  "data": {
    "astroport_factory": "terra14x9fr055x5hvr48hzy2t4q7kvjvfttsvxusa4xsdcy702mnzsvuqprer8r"
  }
}
```

The same request against `https://neutron-api.polkachu.com` with the Neutron Router 2.0 address (`neutron1xuh7nqt486gkvkxdwt773fzs5uptxy0ylzehm3spq7rx8r2kaspqzu0hv6`) returns the Neutron factory.

## Querying with CosmJS

`CosmWasmClient` is a read-only client: it needs no wallet.

```js
import { CosmWasmClient } from "@cosmjs/cosmwasm-stargate";

const client = await CosmWasmClient.connect("https://terra-rpc.publicnode.com");

const config = await client.queryContractSmart(
  "terra1txm8xcy8mete9e5zh5ktqr4jm4cq4ja8djttg3zkqll64x4ksq7qknaesf",
  { config: {} }
);

console.log(config); // { astroport_factory: "terra14x9fr0..." }
```

## Sending Transactions with CosmJS

`SigningCosmWasmClient` signs and broadcasts transactions. Use the address prefix, HD path and gas price of the chain you are on.

```js
import { SigningCosmWasmClient } from "@cosmjs/cosmwasm-stargate";
import { DirectSecp256k1HdWallet } from "@cosmjs/proto-signing";
import { stringToPath } from "@cosmjs/crypto";
import { GasPrice } from "@cosmjs/stargate";

// Terra
const wallet = await DirectSecp256k1HdWallet.fromMnemonic(process.env.MNEMONIC, {
  prefix: "terra",
  hdPaths: [stringToPath("m/44'/330'/0'/0/0")],
});
const client = await SigningCosmWasmClient.connectWithSigner(
  "https://terra-rpc.publicnode.com",
  wallet,
  { gasPrice: GasPrice.fromString("0.015uluna") }
);

// Neutron: prefix "neutron", default HD path, GasPrice.fromString("0.0053untrn")

const [{ address: sender }] = await wallet.getAccounts();

// execute(sender, contract, msg, fee, memo, funds)
const result = await client.execute(
  sender,
  "<contract-address>",
  { some_message: {} },
  "auto",
  "",
  [] // native coins to attach, sorted by denom
);
console.log(result.transactionHash);
```

Gas prices change over time. Check the chain's current minimum before you rely on the values above.
