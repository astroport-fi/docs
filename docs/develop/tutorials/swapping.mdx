# Swapping with CosmJS

## Overview

This tutorial is a complete script that swaps NTRN for ASTRO in the NTRN/ASTRO pool on Neutron with [CosmJS](https://github.com/cosmos/cosmjs). It simulates the swap, derives a `belief_price` from the simulation and sends the swap.

For an explanation of every parameter, CW20 swaps and Terra examples, see [Swapping](trading/swapping). For routes through several pools, see [Multi-hop Routing](trading/multi-hop-routing).

| Name | Value |
| ---- | ----- |
| Chain | Neutron (`neutron-1`) |
| Pool (ASTRO/NTRN) | `neutron1rnz97pgxe0u2a0fduxz4kxape7x32lveu85nl5euf6qhgawkpv7qsmwtd0` |
| NTRN | `untrn` (6 decimals) |
| ASTRO | `factory/neutron1ffus553eet978k024lmssw0czsxwr97mggyv85lpcsdkft8v9ufsz3sa07/astro` (6 decimals) |

<Admonition type="info" title="NOTE">

This tutorial reads the mnemonic from an environment variable to keep the example short. Use proper key management for anything beyond testing, and never commit a mnemonic.

</Admonition>

## Step 1: Install the Libraries

```bash
npm install @cosmjs/cosmwasm-stargate @cosmjs/proto-signing @cosmjs/stargate
```

## Step 2: Connect

```js
import { SigningCosmWasmClient } from "@cosmjs/cosmwasm-stargate";
import { DirectSecp256k1HdWallet } from "@cosmjs/proto-signing";
import { GasPrice } from "@cosmjs/stargate";

const rpc = "https://neutron-rpc.polkachu.com";
const pool = "neutron1rnz97pgxe0u2a0fduxz4kxape7x32lveu85nl5euf6qhgawkpv7qsmwtd0";
const astro = "factory/neutron1ffus553eet978k024lmssw0czsxwr97mggyv85lpcsdkft8v9ufsz3sa07/astro";

const wallet = await DirectSecp256k1HdWallet.fromMnemonic(process.env.MNEMONIC, {
  prefix: "neutron",
});
const [{ address: sender }] = await wallet.getAccounts();

const client = await SigningCosmWasmClient.connectWithSigner(rpc, wallet, {
  gasPrice: GasPrice.fromString("0.0053untrn"),
});
```

On Terra, use `prefix: "terra"`, the HD path `m/44'/330'/0'/0/0` (`hdPaths: [stringToPath("m/44'/330'/0'/0/0")]` from `@cosmjs/crypto`) and a `uluna` gas price. See [Network](network/network-intro) for endpoints.

## Step 3: Simulate the Swap

```js
const offerAmount = "1000000"; // 1 NTRN, in base units

const sim = await client.queryContractSmart(pool, {
  simulation: {
    offer_asset: { info: { native_token: { denom: "untrn" } }, amount: offerAmount },
    ask_asset_info: { native_token: { denom: astro } },
  },
});

console.log(sim); // { return_amount: "...", spread_amount: "...", commission_amount: "..." }
```

## Step 4: Derive `belief_price`

`belief_price` is the offer amount per unit of the return amount, both in base units. It is a decimal string; do not scale it.

```js
const beliefPrice = (Number(offerAmount) / Number(sim.return_amount)).toFixed(18);
const maxSpread = "0.01"; // fail if we would receive more than 1% less than the simulation
```

For example, if the simulation returns `363866` (0.363866 ASTRO) for `1000000` untrn, then `belief_price = 1000000 / 363866 = 2.748264470986571979` and the swap fails if the pool would return less than `363866 * 0.99 = 360227.34`.

## Step 5: Swap

Attach the offer amount as funds:

```js
const result = await client.execute(
  sender,
  pool,
  {
    swap: {
      offer_asset: { info: { native_token: { denom: "untrn" } }, amount: offerAmount },
      ask_asset_info: { native_token: { denom: astro } },
      belief_price: beliefPrice,
      max_spread: maxSpread,
    },
  },
  "auto",
  "",
  [{ denom: "untrn", amount: offerAmount }]
);

console.log(result.transactionHash);
```

## Complete Script

```js
import { SigningCosmWasmClient } from "@cosmjs/cosmwasm-stargate";
import { DirectSecp256k1HdWallet } from "@cosmjs/proto-signing";
import { GasPrice } from "@cosmjs/stargate";

const rpc = "https://neutron-rpc.polkachu.com";
const pool = "neutron1rnz97pgxe0u2a0fduxz4kxape7x32lveu85nl5euf6qhgawkpv7qsmwtd0";
const astro = "factory/neutron1ffus553eet978k024lmssw0czsxwr97mggyv85lpcsdkft8v9ufsz3sa07/astro";

const main = async () => {
  const wallet = await DirectSecp256k1HdWallet.fromMnemonic(process.env.MNEMONIC, {
    prefix: "neutron",
  });
  const [{ address: sender }] = await wallet.getAccounts();
  const client = await SigningCosmWasmClient.connectWithSigner(rpc, wallet, {
    gasPrice: GasPrice.fromString("0.0053untrn"),
  });

  const offerAmount = "1000000"; // 1 NTRN
  const offerInfo = { native_token: { denom: "untrn" } };
  const askInfo = { native_token: { denom: astro } };

  const sim = await client.queryContractSmart(pool, {
    simulation: { offer_asset: { info: offerInfo, amount: offerAmount }, ask_asset_info: askInfo },
  });

  const beliefPrice = (Number(offerAmount) / Number(sim.return_amount)).toFixed(18);

  const result = await client.execute(
    sender,
    pool,
    {
      swap: {
        offer_asset: { info: offerInfo, amount: offerAmount },
        ask_asset_info: askInfo,
        belief_price: beliefPrice,
        max_spread: "0.01",
      },
    },
    "auto",
    "",
    [{ denom: "untrn", amount: offerAmount }]
  );

  console.log(`Swapped. Expected ${sim.return_amount} base units of ASTRO, tx ${result.transactionHash}`);
};

main().catch((error) => {
  console.error("Swap failed:", error);
  process.exit(1);
});
```

Run it with `MNEMONIC="..." node swap.mjs`.
