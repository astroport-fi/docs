# Staking/Unstaking LP Tokens with CosmJS

## Overview

This tutorial is a complete [CosmJS](https://github.com/cosmos/cosmjs) script that stakes a pool's LP tokens in the Incentives contract, checks the position and pending rewards, claims rewards and unstakes. It works with both LP token types: native tokenfactory LP tokens (`factory/<pool>/astroport/share`) and CW20 LP tokens.

For an explanation of each message, see [Staking/Unstaking LP Tokens](../farming/staking-unstaking-lp-tokens) and [Claiming Rewards](../farming/claiming-rewards).

| Chain | Incentives |
| ----- | ---------- |
| Terra | `terra1eywh4av8sln6r45pxq45ltj798htfy0cfcf7fy3pxc2gcv6uc07se4ch9x` |
| Neutron | `neutron173fd8wpfzyqnfnpwq2zhtgdstujrjz2wkprkjfr6gqg4gknctjyq6m3tch` |

<Admonition type="info" title="NOTE">

There are no ASTRO emissions. Staked LP tokens earn only the external incentive schedules added to their pool. Check a pool's `pool_info` in Incentives to see whether it has any.

</Admonition>

## Step 1: Connect

The script uses Terra and the LUNA/USDC pool. For Neutron, change the constants, use `prefix: "neutron"` without `hdPaths`, and an `untrn` gas price.

```js
import { SigningCosmWasmClient, toBinary } from "@cosmjs/cosmwasm-stargate";
import { DirectSecp256k1HdWallet } from "@cosmjs/proto-signing";
import { stringToPath } from "@cosmjs/crypto";
import { GasPrice } from "@cosmjs/stargate";

const rpc = "https://terra-rpc.publicnode.com";
const incentives = "terra1eywh4av8sln6r45pxq45ltj798htfy0cfcf7fy3pxc2gcv6uc07se4ch9x";
const pool = "terra1v3lqxl0eyte9x3nhdgcj8hwvjq76aupnnzz0yll8mxs5cckc29pqvg2scu"; // LUNA/USDC

const wallet = await DirectSecp256k1HdWallet.fromMnemonic(process.env.MNEMONIC, {
  prefix: "terra",
  hdPaths: [stringToPath("m/44'/330'/0'/0/0")],
});
const [{ address: sender }] = await wallet.getAccounts();
const client = await SigningCosmWasmClient.connectWithSigner(rpc, wallet, {
  gasPrice: GasPrice.fromString("0.015uluna"),
});
```

## Step 2: Find the LP Token

```js
const { liquidity_token: lpToken } = await client.queryContractSmart(pool, { pair: {} });
const isNativeLp = lpToken.startsWith("factory/");
```

## Step 3: Stake

Native LP tokens are attached to `deposit`. CW20 LP tokens are sent to Incentives with a `send` that embeds `deposit`.

```js
const stake = async (amount) => {
  if (isNativeLp) {
    return client.execute(sender, incentives, { deposit: {} }, "auto", "", [
      { denom: lpToken, amount },
    ]);
  }
  return client.execute(
    sender,
    lpToken,
    { send: { contract: incentives, amount, msg: toBinary({ deposit: {} }) } },
    "auto"
  );
};
```

## Step 4: Check the Position

```js
const staked = await client.queryContractSmart(incentives, {
  deposit: { lp_token: lpToken, user: sender },
});

const pending = await client.queryContractSmart(incentives, {
  pending_rewards: { lp_token: lpToken, user: sender },
});
```

## Step 5: Claim Rewards

```js
const claim = () =>
  client.execute(sender, incentives, { claim_rewards: { lp_tokens: [lpToken] } }, "auto");
```

## Step 6: Unstake

`withdraw` returns the LP tokens and pays out pending rewards in the same transaction.

```js
const unstake = (amount) =>
  client.execute(sender, incentives, { withdraw: { lp_token: lpToken, amount } }, "auto");
```

## Complete Script

```js
import { SigningCosmWasmClient, toBinary } from "@cosmjs/cosmwasm-stargate";
import { DirectSecp256k1HdWallet } from "@cosmjs/proto-signing";
import { stringToPath } from "@cosmjs/crypto";
import { GasPrice } from "@cosmjs/stargate";

const rpc = "https://terra-rpc.publicnode.com";
const incentives = "terra1eywh4av8sln6r45pxq45ltj798htfy0cfcf7fy3pxc2gcv6uc07se4ch9x";
const pool = "terra1v3lqxl0eyte9x3nhdgcj8hwvjq76aupnnzz0yll8mxs5cckc29pqvg2scu";
const amount = "1000000"; // LP tokens to stake, in base units

const main = async () => {
  const wallet = await DirectSecp256k1HdWallet.fromMnemonic(process.env.MNEMONIC, {
    prefix: "terra",
    hdPaths: [stringToPath("m/44'/330'/0'/0/0")],
  });
  const [{ address: sender }] = await wallet.getAccounts();
  const client = await SigningCosmWasmClient.connectWithSigner(rpc, wallet, {
    gasPrice: GasPrice.fromString("0.015uluna"),
  });

  const { liquidity_token: lpToken } = await client.queryContractSmart(pool, { pair: {} });
  const isNativeLp = lpToken.startsWith("factory/");

  // Stake
  const stakeTx = isNativeLp
    ? await client.execute(sender, incentives, { deposit: {} }, "auto", "", [
        { denom: lpToken, amount },
      ])
    : await client.execute(
        sender,
        lpToken,
        { send: { contract: incentives, amount, msg: toBinary({ deposit: {} }) } },
        "auto"
      );
  console.log("Staked:", stakeTx.transactionHash);

  // Position and pending rewards
  const staked = await client.queryContractSmart(incentives, {
    deposit: { lp_token: lpToken, user: sender },
  });
  const pending = await client.queryContractSmart(incentives, {
    pending_rewards: { lp_token: lpToken, user: sender },
  });
  console.log("Staked amount:", staked, "Pending rewards:", pending);

  // Claim
  const claimTx = await client.execute(
    sender,
    incentives,
    { claim_rewards: { lp_tokens: [lpToken] } },
    "auto"
  );
  console.log("Claimed:", claimTx.transactionHash);

  // Unstake everything
  const unstakeTx = await client.execute(
    sender,
    incentives,
    { withdraw: { lp_token: lpToken, amount: staked } },
    "auto"
  );
  console.log("Unstaked:", unstakeTx.transactionHash);
};

main().catch((error) => {
  console.error(error);
  process.exit(1);
});
```
