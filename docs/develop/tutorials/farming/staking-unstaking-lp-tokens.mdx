# Staking/Unstaking LP Tokens

## Overview

LP tokens staked in the [Incentives](/docs/develop/smart-contracts/tokenomics/incentives) contract earn the incentive rewards scheduled for their pool. Unstaked LP tokens earn swap fees only (fees accrue inside the pool for every LP token, staked or not).

| Chain | Incentives |
| ----- | ---------- |
| Terra | `terra1eywh4av8sln6r45pxq45ltj798htfy0cfcf7fy3pxc2gcv6uc07se4ch9x` (1.5.0) |
| Neutron | `neutron173fd8wpfzyqnfnpwq2zhtgdstujrjz2wkprkjfr6gqg4gknctjyq6m3tch` (1.4.0) |

<Admonition type="info" title="No ASTRO emissions">

Astroport no longer emits ASTRO to pools: Incentives' ASTRO rate is zero. Rewards for staked LP tokens come only from external incentive schedules that anyone can add to a pool (see [Claiming Rewards](claiming-rewards#where-rewards-come-from)). Staking a pool's LP tokens earns nothing extra unless that pool has an active schedule. The legacy Generator contracts still exist on both chains, but emissions there have ended; use Incentives.

</Admonition>

Any LP token of a pool registered in the factory can be staked. Staking, unstaking and claiming all settle your pending rewards first: every `deposit` and `withdraw` also pays out what you have earned so far.

## Staking LP Tokens

How you stake depends on the LP token type, which the pool's `pair` query returns as `liquidity_token`.

### Native LP Tokens

Call `deposit` on Incentives and attach the LP tokens (exactly one coin) as funds:

```json
{
  "deposit": {}
}
```

```js
const incentives = "neutron173fd8wpfzyqnfnpwq2zhtgdstujrjz2wkprkjfr6gqg4gknctjyq6m3tch";
const lpDenom = "factory/neutron1...pool/astroport/share";

await signingClient.execute(
  sender,
  incentives,
  { deposit: {} },
  "auto",
  "",
  [{ denom: lpDenom, amount: "1000000" }]
);
```

`deposit` takes an optional `recipient` to stake on behalf of another address: `{"deposit": {"recipient": "neutron1..."}}`.

### CW20 LP Tokens

Call `send` on the LP token contract with Incentives as `contract`. The `msg` is the base64 encoding of `{"deposit":{}}`.

```json
{
  "send": {
    "contract": "terra1eywh4av8sln6r45pxq45ltj798htfy0cfcf7fy3pxc2gcv6uc07se4ch9x",
    "amount": "1000000",
    "msg": "eyJkZXBvc2l0Ijp7fX0="
  }
}
```

```js
import { toBinary } from "@cosmjs/cosmwasm-stargate";

const incentives = "terra1eywh4av8sln6r45pxq45ltj798htfy0cfcf7fy3pxc2gcv6uc07se4ch9x";
const lpToken = "terra1s275y73lfupag0g03nglxaedfnsw5z4m5zc9wk66guy503zuw5ss889tlx"; // LUNA/USDC LP

await signingClient.execute(
  sender,
  lpToken, // the LP token contract
  {
    send: {
      contract: incentives,
      amount: "1000000",
      msg: toBinary({ deposit: {} }),
    },
  },
  "auto"
);
```

### Staking While Providing Liquidity

`provide_liquidity` with `"auto_stake": true` mints the LP tokens and stakes them in Incentives in the same transaction. See [Providing/Withdrawing Liquidity](providing-withdrawing-liquidity).

## Unstaking LP Tokens

Call `withdraw` on Incentives with the LP token (denom or CW20 address) and the amount. The LP tokens and any pending rewards are sent to you.

```json
{
  "withdraw": {
    "lp_token": "terra1s275y73lfupag0g03nglxaedfnsw5z4m5zc9wk66guy503zuw5ss889tlx",
    "amount": "1000000"
  }
}
```

```js
await signingClient.execute(
  sender,
  incentives,
  { withdraw: { lp_token: lpToken, amount: "1000000" } },
  "auto"
);
```

The amount can't be more than you have staked. To leave a [withdraw-only (exit-only) pool](providing-withdrawing-liquidity#withdraw-only-exit-only-pools), unstake its LP tokens here first, then withdraw them from the pool.

## Checking Your Position

The amount you have staked (`deposit` returns a `Uint128`):

```json
{
  "deposit": {
    "lp_token": "terra1s275y73lfupag0g03nglxaedfnsw5z4m5zc9wk66guy503zuw5ss889tlx",
    "user": "terra1...you"
  }
}
```

Your pending rewards for that LP token, as a list of assets (the query fails if you have no position in that pool):

```json
{
  "pending_rewards": {
    "lp_token": "terra1s275y73lfupag0g03nglxaedfnsw5z4m5zc9wk66guy503zuw5ss889tlx",
    "user": "terra1...you"
  }
}
```
