# Creating and Seeding a Pool

## Overview

This tutorial creates a new pool with [CosmJS](https://github.com/cosmos/cosmjs) and makes the first deposit into it. It covers:

- **Creating a pair** through the factory.
- **Finding the pool address** and its LP token.
- **Approving CW20 tokens** (only if one of the assets is a CW20).
- **Providing the first liquidity**, which sets the pool's starting price.

The example creates an xyk pool on Neutron for a tokenfactory token against NTRN. The same steps work on Terra with the Terra factory, Terra denoms and the Terra wallet settings shown below. For the other pool types and their `init_params`, see [Creating a Pair](farming/creating-a-pair).

| Chain | Factory |
| ----- | ------- |
| Terra | `terra14x9fr055x5hvr48hzy2t4q7kvjvfttsvxusa4xsdcy702mnzsvuqprer8r` |
| Neutron | `neutron1hptk0k5kng7hjy35vmh009qd5m6l33609nypgf2yc6nqnewduqasxplt4e` |

<Admonition type="info" title="NOTE">

This tutorial reads the mnemonic from an environment variable to keep the example short. Use proper key management for anything beyond testing, and never commit a mnemonic.

</Admonition>

## Setup

### Step 1: Import the Libraries

```js
import { SigningCosmWasmClient } from "@cosmjs/cosmwasm-stargate";
import { DirectSecp256k1HdWallet } from "@cosmjs/proto-signing";
import { GasPrice } from "@cosmjs/stargate";
```

### Step 2: Define Constants

```js
const rpc = "https://neutron-rpc.polkachu.com";
const factory = "neutron1hptk0k5kng7hjy35vmh009qd5m6l33609nypgf2yc6nqnewduqasxplt4e";
const myToken = "factory/neutron1...creator/mytoken"; // the token you created
```

### Step 3: Create the Wallet and Signing Client

```js
const wallet = await DirectSecp256k1HdWallet.fromMnemonic(process.env.MNEMONIC, {
  prefix: "neutron",
});
const [{ address: sender }] = await wallet.getAccounts();

const client = await SigningCosmWasmClient.connectWithSigner(rpc, wallet, {
  gasPrice: GasPrice.fromString("0.0053untrn"),
});
```

On Terra, use `prefix: "terra"`, add `hdPaths: [stringToPath("m/44'/330'/0'/0/0")]` (`stringToPath` comes from `@cosmjs/crypto`) and a `uluna` gas price such as `0.015uluna`.

### Step 4: Wrap the Code in an Async Function

```js
const main = async () => {
  // Place the code from the next sections here
};

main().catch((error) => {
  console.error("An error occurred:", error);
  process.exit(1);
});
```

## Create the Pair

```js
const assetInfos = [
  { native_token: { denom: myToken } },
  { native_token: { denom: "untrn" } },
];

const createTx = await client.execute(
  sender,
  factory,
  { create_pair: { pair_type: { xyk: {} }, asset_infos: assetInfos } },
  "auto"
);
console.log("Pair created:", createTx.transactionHash);
```

`create_pair` fails if the factory already has a pool for this asset pair. On Terra, CW20 tokens are written as `{ token: { contract_addr: "terra1..." } }`.

## Find the Pool Address

```js
const pairInfo = await client.queryContractSmart(factory, {
  pair: { asset_infos: assetInfos },
});

const pool = pairInfo.contract_addr;
const lpToken = pairInfo.liquidity_token; // factory/<pool>/astroport/share on Neutron
console.log({ pool, lpToken });
```

## Approve CW20 Tokens (CW20 Assets Only)

If one of the assets is a CW20 token, allow the pool to transfer the amount you will deposit. Skip this for native assets.

```js
await client.execute(
  sender,
  "<cw20-token-address>",
  { increase_allowance: { spender: pool, amount: "1000000" } },
  "auto"
);
```

See the [CW20 spec](https://github.com/CosmWasm/cw-plus/blob/main/packages/cw20/README.md) for allowances.

## Provide the First Liquidity

The first deposit sets the pool's price: depositing 1,000 MYTOKEN and 500 NTRN starts the pool at 0.5 NTRN per MYTOKEN. Match the market price as closely as you can; any difference is an arbitrage opportunity paid for by your deposit. Part of the first deposit's LP tokens stays locked in the pool.

```js
const myTokenAmount = "1000000000"; // 1,000 MYTOKEN (6 decimals)
const ntrnAmount = "500000000";     // 500 NTRN

const provideTx = await client.execute(
  sender,
  pool,
  {
    provide_liquidity: {
      assets: [
        { info: { native_token: { denom: myToken } }, amount: myTokenAmount },
        { info: { native_token: { denom: "untrn" } }, amount: ntrnAmount },
      ],
      auto_stake: false,
    },
  },
  "auto",
  "",
  // native funds, sorted by denom ("factory/..." sorts before "untrn")
  [
    { denom: myToken, amount: myTokenAmount },
    { denom: "untrn", amount: ntrnAmount },
  ]
);
console.log("Liquidity provided:", provideTx.transactionHash);
```

Set `auto_stake: true` to stake the LP tokens in the Incentives contract in the same transaction. Staked LP tokens earn rewards only if the pool has incentive schedules: see [Claiming Rewards](farming/claiming-rewards#where-rewards-come-from) for how to add one.
