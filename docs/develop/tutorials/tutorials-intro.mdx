# Tutorials

Apply and improve your developer skills with hands-on tutorials. The examples run against Astroport's contracts on Terra and Neutron and use [CosmJS](https://github.com/cosmos/cosmjs).

- [Network](network/network-intro): connect to Terra and Neutron, query contracts and send transactions.
- [Trading](trading/trading-intro): swap in a pool and route swaps through several pools with Router 2.0.
- [Farming](farming/farming-intro): create pools, provide and withdraw liquidity, stake LP tokens in Incentives and claim rewards.
- [Creating a Token](creating-a-token/creating-a-token-intro): create a tokenfactory token on Terra or Neutron.
- [Creating and Seeding a Pool](creating-and-seeding-a-pool): an end-to-end script that creates a pool and makes the first deposit.
- [Swapping with CosmJS](swapping): an end-to-end swap script.
- [Staking/Unstaking LP Tokens with CosmJS](staking-unstaking-lp-tokens/staking-unstaking-lp-tokens-intro): an end-to-end staking script.
- [Querying Oracle Prices](querying-oracle-prices): read recent prices from a pool.

Contract addresses are on the [Contract Addresses](/docs/develop/smart-contracts/contract-addresses) page. Astroport is in [long-term support](/docs/learn/long-term-support): governance and ASTRO emissions are retired, so there are no governance or emissions tutorials.
